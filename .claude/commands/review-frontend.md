description: Run a structured frontend quality review of the current changes.
---

Review the current frontend changes without modifying files.

1. Inspect repository instructions and the git diff.
2. Identify the changed routes, components, and user journeys.
3. Review functional behavior, responsive design, interaction states, accessibility, and likely performance risks.
4. Run only relevant checks that are available and safe.
5. Report findings by severity with file references and concrete remediation.
6. Separate verified results from assumptions and untested areas.

Do not claim visual inspection without a rendered preview. Do not claim tests passed unless executed.
