# Accessibility Review Workflow

1. Check landmarks, heading order, semantic elements, and accessible names.
2. Navigate the complete journey using only a keyboard.
3. Confirm focus is visible, logical, and managed after dialogs or route changes.
4. Check form labels, instructions, required fields, and error associations.
5. Check text and control contrast; ensure meaning is not conveyed by color alone.
6. Verify dialogs, menus, tabs, and disclosure patterns use appropriate semantics and keyboard behavior.
7. Check zoom/reflow and reduced-motion preferences.
8. Run automated tools if available and document manual checks separately.

Report each finding with severity, location, impact, fix, and verification. Automated tools are useful but do not prove conformance.
